# 领域词汇表

本文件定义医保项目目录映射的核心对象、稳定枚举与语义规则。事件信封与枚举的机器可读形式见 `contracts/domain.schema.json`，各事件载荷约定见 `docs/events.md`。

## 目标与阶段

- 第一阶段：让每一条具体账单都能被解释——从任一费用行回到国家项目、地方编码、审核过程和当时版本。
- 后续阶段：在统一版本语义下，逐步形成国家目录与各省目录之间的完整映射服务。

## 核心对象（聚合）

| 聚合 | 说明 |
| --- | --- |
| `catalog_revision` 目录版本 | 国家目录或地方目录的一次发布版本，记录目录范围、生效区域与生效时间。 |
| `service_item` 服务项目 | 目录中一个项目的版本，包含项目定义、计价单位、服务边界与支付条件。 |
| `mapping_candidate` 自动候选 | 系统生成的候选映射，只展示相似依据，未审核前不得进入结算。 |
| `mapping_claim` 映射主张 | 地方编码与国家项目之间的映射主张及其正式结果，含组成明细与审核状态。 |
| `expert_opinion` 专家意见 | 审核过程中专家就映射主张或异议给出的意见。 |
| `split_validation` 拆分校验 | 对组合拆分结果的重复计费边界校验。 |
| `objection` 异议 | 省级人员附证据提出的异议，及发布方采纳或驳回的理由。 |
| `release_batch` 发布批次 | 目录或映射版本的发布单元；更正批次是其中一类。 |
| `settlement_snapshot` 结算快照 | 一次跨省结算请求冻结的目录版本与映射版本集合。 |
| `bill_explanation` 账单解释 | 对一条费用行的解释记录，含追溯引用与缺失条件。 |

## 版本化

国家目录、地方目录、项目定义、计价单位、服务边界、支付条件、生效区域、映射主张、专家意见与发布批次均要版本化：

- 目录与项目的每次变化产生新版本，旧版本保留，供历史费用解释。
- 事件信封中的 `version` 是事件所涉对象的版本号；同一对象版本可对应多个事件（例如同一版主张的提出与审核通过）。
- 对象引用统一写作 `<aggregate_id>@v<version>`，例如 `claim-0001@v2`。

## 稳定枚举

| 枚举 | 取值 | 含义 |
| --- | --- | --- |
| `catalog_scope` 目录范围 | `national` / `provincial` | 国家目录 / 地方目录 |
| `mapping_result_kind` 映射结果类别 | `one_to_one` / `one_to_many` / `many_to_one` / `unmappable` | 一对一 / 一对多 / 多对一 / 不可映射，均为审核后的正式结果 |
| `claim_status` 主张状态 | `proposed` / `approved` / `rejected` | 待审核 / 审核通过 / 审核驳回；仅 `approved` 可进入结算 |
| `similarity_basis` 相似依据 | `name_similarity` / `unit_consistency` / `boundary_overlap` | 名称相似 / 计价单位一致 / 服务边界重叠 |
| `combo_category` 组合类别 | `nursing` / `scale` / `anesthesia` | 护理 / 量表 / 麻醉；新类别经登记后扩展 |
| `split_check_result` 拆分校验结果 | `no_overlap` / `overlap_detected` | 边界无重叠 / 存在重复计费风险 |
| `objection_resolution` 异议处理结果 | `adopted` / `rejected` | 采纳（转入更正批次）/ 驳回；均须记录理由 |
| `explanation_outcome` 解释结果 | `explained` / `missing_conditions` / `unmappable` | 已解释 / 缺少支付条件 / 正式不可映射 |
| `batch_kind` 批次类别 | `regular` / `correction` | 常规发布批次 / 更正批次 |

## 语义规则

1. **版本解释**：费用按服务发生时的生效版本解释；政策生效前的费用继续按旧版解释。
2. **审核门禁**：自动候选只展示相似依据；只有审核通过（`approved`）的映射主张版本才能进入结算。一对多、多对一与不可映射都是审核后的正式结果。
3. **拆分校验**：护理、量表、麻醉等组合拆分必须通过重复计费边界校验（`no_overlap`），方可审核通过，避免漏付与重复计费。
4. **快照冻结**：每次跨省结算请求冻结所用目录版本与映射版本；之后的目录或映射变化不影响该快照。
5. **更正批次**：冻结后的变化通过更正批次发布新版本，不回写已冻结快照。
6. **异议处理**：省级人员可附证据提出异议；发布方必须记录采纳或驳回及理由；采纳的异议经更正批次落地。
7. **提交前检查**：医院提交前可对草稿费用请求解释；结果为 `missing_conditions` 时列出缺失的支付条件。
8. **可追溯**：任一费用可回到国家项目、地方编码、映射版本、审核过程与当时目录版本。
